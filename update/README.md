# Что нового — по версиям

Файл на каждую версию: `update/<версия>.md` (версия — как в `package.json`). Его использует:

- **Орион** — зачитывает голосом: «что нового?», «что нового в версии 0.3.0?», а после обновления сам
  предлагает рассказать (навык `src/skills/updates.js`). Если обновились через несколько версий — расскажет про все.
- **Релиз на GitHub** — тот же текст становится описанием релиза (`.github/workflows/release.yml`).
- **Тест** — `npm test` падает, если для версии из `package.json` файла нет: поднимаете версию — пишете, что нового.

## Формат

```markdown
# 0.5.0 — 2026-11-01

Вводная фраза — по желанию.

- Пункт — одна-две законченные фразы, как их сказать вслух.
- Без технических слов: «Окно больше не висит поверх всех», а не «alwaysOnTop: false».
```

Пишите для слуха: Орион читает пункты подряд (не больше десяти, остальное — «и ещё N»), разметка
(`**`, ссылки, код) при чтении снимается. Ударения в новых словах проверяет `npm run stress-phrases -- --new`.
